📐 CONFUSION MATRIX AÇIKLAMASI:

                    Tahmin Edilen
                 Negative  Positive
Gerçek         ┌──────────────────┐
Negative       │ TN      │  FP     │
               ├──────────────────┤
Positive       │ FN      │  TP     │
               └──────────────────┘

TN: Doğru Negatif    (Negatifi doğru tahmin)
FP: Yanlış Pozitif   (Negatifi pozitif tahmin)
FN: Yanlış Negatif   (Pozitifi negatif tahmin)
TP: Doğru Pozitif    (Pozitifi doğru tahmin)

═══════════════════════════════════════════════════════════════════════════

📊 METRİK REHBERI:

Metrik           │ Formül                │ En İyi  │ Kullanım
─────────────────┼───────────────────────┼─────────┼──────────
Accuracy         │ (TP+TN)/Total         │ > 0.85  │ Genel
Precision        │ TP/(TP+FP)            │ > 0.80  │ False Positive risk
Recall (TPR)     │ TP/(TP+FN)            │ > 0.75  │ False Negative risk
F1-Score         │ 2·P·R/(P+R)           │ > 0.80  │ Dengesiz veri
ROC-AUC          │ Eğri alt alanı        │ > 0.85  │ Sınıf dengesizliği
PR-AUC           │ Precision-Recall      │ > 0.80  │ Nadir sınıflar
Balanced Acc.    │ (Sensitivity+TNR)/2   │ > 0.80  │ İşletme metrikleri
